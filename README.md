# Efoil Landing Page

A landing page for an eFoil brand, built from scratch using HTML and CSS.

I made this project to practice building a complete website layout without following a full tutorial. The main focus was on the design, spacing, sections, cards, and making the page responsive.

## Live Website

[efoil-landing-page.netlify.app](https://efoil-landing-page.netlify.app/)

## Preview

![Efoil Landing Page](images/preview.png)

## What I Built

* Hero section with call-to-action buttons
* Navigation bar
* Product showcase sections
* Product cards for different eFoils
* Feature/trust section
* Image-based sections
* Customer reviews
* Responsive layout for smaller screens

## Technologies Used

* HTML5
* CSS3
* Font Awesome

## What I Practiced

* Flexbox
* CSS Grid
* Responsive design
* Background images
* Positioning and spacing
* Creating reusable card layouts
* Building a complete page from scratch

## Note

This is a frontend practice project. The buttons and product sections are mainly for the UI and don't represent a real eFoil store.
